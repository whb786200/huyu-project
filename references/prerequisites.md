# 代建项目管理资料生成技能 — 其他项目采用先决条件

## 概述

本技能（huyu-project）为代建项目管理提供全套文档自动生成能力，包括：
- 管理制度体系（25份）
- 安全管理行为资料（16组）
- 质量管理行为资料（8组/22份）
- 施工日报生成
- 日报智能检查提醒（联动安全/质量检查）
- 大型会议/专项检查方案生成
- 桌面考核资料文件夹自动同步
- 百度OCR图片/PDF识别

其他项目如需采用本技能，需满足以下先决条件。

## 二、软件环境要求

### 2.1 Python 环境

- Python 3.8+（推荐 3.10+）
- 必装库：`python-docx`、`requests`

```bash
pip install python-docx requests
```

### 2.2 操作系统

- Windows（推荐，因路径和字体兼容性）
- Linux/macOS 需额外处理中文字体

### 2.3 中文字体

以下字体需已安装在系统中：
- 方正小标宋简体（标题）
- 黑体（副标题）
- 仿宋（正文）
- 宋体/楷体（辅助）

> 若缺少方正小标宋，可用"华文中宋"或"黑体"替代。

---

## 三、考核评价表（核心依据）

### 3.1 评价表来源

本技能的文档体系基于中铁置业集团的考核评价表。采用本技能的项目需提供：

1. **代建类项目安全管理行为考核评价表（附表5）** — 含10大考核项目、100分
2. **代建类项目质量管理行为考核评价表（附表2）** — 含8大考核项目、100分

### 3.2 评价表格式

提供 Excel 格式（.xlsx），结构包含：序号、考核项目、考核内容、分值、问题及评述、考核得分。

### 3.3 评价表用途

- 决定 gen_*.py 脚本的文件数量和内容
- 决定桌面文件夹体系结构
- 决定检查提醒的触发条件

## 五、目录结构要求

采用本技能需建立以下目录结构：

```
D:\项目名称\
├── 整改资料\
│   ├── 管理制度文件\          # gen_*.py 脚本和输出 docx
│   └── 合规手续\              # 合规手续PDF原件
└── （其他项目文件）
```

桌面同步目录（自动创建）：
```
桌面\项目名称考核资料\
├── 安全管理行为考核资料（附表5）\
│   ├── 00、考核项目索引.docx
│   ├── 1、机构人员\
│   ├── 2、安全生产责任\
│   └── ...
└── 质量管理行为考核资料（附表2）\
    ├── 00、考核项目索引.docx
    ├── 1、质量管理文件的制定及执行情况\
    └── ...
```

## 六、需定制修改的内容

采用本技能后，需根据新项目实际情况修改以下内容：

### 6.1 项目信息（所有 gen_*.py 脚本）

- 项目名称、代码、面积、投资额
- 各参建单位名称、人员姓名
- 建筑单体参数
- 合规手续信息

### 6.2 gen_desktop_folders.py

- `SAFETY_ITEMS` 和 `QUALITY_ITEMS` 的 `gen_files` 映射
- 需与新项目的实际文件名对应
- 路径配置（`GEN_DIR`、`BASE_DIR`）

### 6.3 gen_daily_inspector.py

- `STAGE_CHECKS` 施工阶段关键词（如楼号变化）
- `SPECIAL_INSPECTIONS` 专项检查触发条件
- 检查内容可根据项目特点增减

### 6.4 gen_meeting_planner.py

- `PROJECT` 字典中的项目信息
- `MEETING_TEMPLATES` 中的参会人员
- `INSPECT_TEMPLATES` 中的检查内容

### 6.5 SKILL.md

- 触发词、路径、项目描述

## 七、实施步骤建议

1. **收集信息**（1-2天）：收集项目基本信息、人员通信录、合规手续、考核评价表
2. **建立目录**（半天）：创建项目目录结构
3. **修改脚本**（2-3天）：批量替换 gen_*.py 中的项目信息
4. **验证生成**（1天）：运行所有脚本，检查输出文档
5. **配置联动**（半天）：配置桌面文件夹同步、日报检查提醒
6. **持续维护**：随施工进度更新日报和检查记录

---

## 八、风险提示

- **虚构人员**：所有人员必须使用真实姓名，不得编造
- **数据准确性**：面积、投资额等必须与正式文件一致
- **考核表匹配**：文档内容必须与具体项目的考核评价表一一对应
- **日期逻辑**：施工进度相关日期必须符合实际进度，不得超前
- **字体兼容**：目标机器需安装所需中文字体
